# 🍳 Micro App Costos & Precios para Cocina y Emprendimientos Gastronómicos

Aplicación web ligera (HTML5 + Vanilla JS + Tailwind CSS) diseñada exclusivamente para pasteleras, pizzeros, rotiserías y personas que elaboran y venden comida casera por unidad, por kilo o por docena en Argentina.

## Características
- 🥫 **Despensa de Insumos & Precios del Súper:** Registro de materias primas con conversión automática a costo por gramo, mililitro o unidad.
- 📦 **Separación clara de Ingredientes vs Packaging:** Cajas de pizza, bases de fibrofácil, bolsas, folex y stickers calculados por separado.
- 🔘 **Interruptor Activar / Desactivar sin borrar:** Permite descartar temporalmente un ingrediente o packaging y volverlo a activar cuando sea necesario sin reescribir nada.
- ⚖️ **3 Modos de Venta con Rendimiento exacto:**
  - 🍕 *Por Unidad:* Pizzas listas para hornear, tartas, budines.
  - 🎂 *Por Kilo:* Tortas de cumpleaños, pastas caseras, comidas preparadas.
  - 🥟 *Por Docena:* Pastelitos criollos, empanadas, medialunas, alfajores.
- ⏱️ **Mano de Obra & Gas opcional:** Switch para sumar horas de trabajo y porcentaje de gas/luz.
- ⚡ **Botón Anti-Inflación Global:** Permite aumentar toda la despensa un +5%, +10% o +15% de un solo golpe, recalculando todas las recetas al instante.
- 🎁 **Calculadora de Promos & Combos:** Armado de combos de varios productos con descuento y cálculo de ganancia neta.
- 💬 **Cotización limpia para WhatsApp:** Genera el texto listo para enviar al cliente con 1 clic.
- 📷 **Logo o Foto del Emprendimiento:** Carga y optimización con canvas en vivo.
- ☁️ **Copia de seguridad automática en Google Drive:** Carpeta *Copia de seguridad Costos Comida*.
- 📊 **Exportación:** Planilla Excel (CSV) y respaldo JSON local.
